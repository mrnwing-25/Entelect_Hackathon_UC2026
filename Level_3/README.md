# The Ranger's Rescue Route — Bonus Level

## Overview

This project contains a Python solution for the Bonus Level of
"The Ranger's Rescue Route" shortest-path optimisation challenge.

The objective is to find a route that:

1. Starts at `A`.
2. Visits all 24 required stations.
3. Ends at `B`.
4. Minimises the total risk-adjusted route cost.

The Bonus Level contains:

- 100 nodes
- 287 edges
- 24 required stations
- Start node: `A`
- End node: `B`
- Time weighting: Yes
- Risk weighting: Yes

# Requirements

Python 3.8 or newer is recommended.

The solution only uses Python's standard library.

No external packages need to be installed.

The program uses:

json for reading and writing JSON.
heapq for the priority queue used by Dijkstra's algorithm.

# Running the Program

Open a terminal in the project directory.

Run:

```bash
python level_3.py
```

On some systems, you may need:

```bash
python3 level_3.py
```
The program expects 1.txt to be in the same directory as
`level_3.py`.
